# Recipe Browser 🥣

This is a website designed to help find and discover recipes. Is was made with **Python**, **Flask** and **Bootstrap 5**.
The data comes from the **The Meal DB API** (https://www.themealdb.com/api.php).

## Features
* **Search recipe by meal name**
* **Search recipe by category, country or main ingredient**
* **Retrieval of a random recipe from the database**
* **Simple and Intuitive Design**

## Project Structure
* **Backend**: Python, Flask
* **Frontend**: Jinja, Bootstrap 5, CSS
* **Data**: from **The Meal DB API** (https://www.themealdb.com/api.php)
